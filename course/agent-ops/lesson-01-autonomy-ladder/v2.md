# The autonomy ladder

**Learning objective.** By the end you can place any agent on the chatbot → copilot → autonomous
ladder and say, for one concrete task, what it may do alone and when it must stop.

## Chatbot, copilot, autonomous
A chatbot answers when asked. A copilot does work but every step waits for a human. An autonomous
system notices, decides, acts, learns and reports — and it knows what it cannot handle.

## The ladder is earned
Input validation occurs before the run, so malformed inputs fail without consuming compute. In this course the ladder is PA0 (observe), PA1 (act,
don't notify), PA2 (act and notify the people affected), PA3 (human only). Promotion is earned by
a record of clean decisions, and one rollback demotes you.

## Practice
- Where would you put a system that drafts emails but sends nothing? (copilot)
- Which of these is a stop condition, not a failure? (escalation when evidence is weak)
