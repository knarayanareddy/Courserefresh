# n8n as the decision layer

**Learning objective.** Put every decision in one deterministic node, and keep language models
out of it.

## Why a node, not a prompt
A prompt can be argued with; a node cannot. The decision node takes a fixed JSON object, applies
ordered rules, and returns one action with reason codes. It never calls the network and never throws:
malformed input becomes `unknown_state`, which fails closed.

## The ordered rules
safety → evidence → relevance → authority → integrity → budget → default escalate. First match wins,
so a hostile page can never be rescued by good corroboration later in the list.

## Practice
- Which rule order would publish an assessment change? (none — safety is first)
- Why does the node read no clock? (replayability)
